# Security & Domain Notes
- Add `.env*` to `.gitignore` while allowing `.env.example` with placeholders.
- Use environment variables in local development and deployment provider secret settings.
- Enable GitHub secret scanning / push protection if available.
- Audit other repositories for hard-coded credentials.
- Do not include real credentials in issue reports or prompts to coding agents.

## CV privacy
Public portfolio CV should generally omit:
- Residential street address
- Personal phone (optional; can be provided directly to recruiters)
- Sensitive personal identifiers
Include city/region and professional email instead.
