# Project Brief — Edgi Axel Personal Website

## Purpose
Create a professional, memorable personal website that serves as the canonical public profile and portfolio for Edgi Axel Limandibrata. It must support job applications, hackathons, collaborations, and future career changes without locking the identity into one specialization.

## Current professional positioning
**Web Developer | AI/ML Enthusiast | Creative Technology**

This positioning is intentionally current and flexible. The user is actively building primarily full-stack web projects and exploring AI/ML; do not claim AI Engineer, ML Engineer, or senior/full-stack mastery without evidence.

## Audience
1. Recruiters and hiring managers
2. Technical collaborators and hackathon teams
3. Developers evaluating public projects
4. Potential clients for relevant technical/creative work (creative identity kept distinct)

## Primary conversion actions
- View/download CV
- Explore projects
- Contact via professional email
- Visit GitHub / LinkedIn

## MVP scope
- Responsive landing page
- About/profile section
- Selected project showcase and project directory
- CV page with English and Indonesian versions
- PDF export via browser print (selectable text, A4, no screenshot/raster CV)
- Contact/social links
- Metadata, favicon, Open Graph basics
- Deployment to `edgiaxel.tech`

## Out of scope for MVP
- Database/CMS
- Login/authentication
- Admin dashboard
- Automated resume generation from GitHub API
- AI-generated CV content
- Blog CMS
- E-commerce/digital product storefront
- Heavy 3D/WebGL experience
- Complex scroll hijacking
- Linking or merging the Edgi Axel professional identity with Axel Zeed VTuber identity

## Product principles
- Content first, effects second.
- Strong typography and hierarchy.
- Performance on modest devices.
- Accessibility and keyboard support.
- ATS-readable CV.
- Verifiable project claims.
- No secrets in repository history.
- Privacy-conscious public contact information.
